# Getting help

- **Using the app:** see the [desktop guide](desktop/README.md). Download the
  newest installer from the
  [latest release](https://github.com/algorithco/algorith-shot-releases/releases/latest).
- **Something doesn't work, or you have an idea:** open an
  [issue](https://github.com/algorithco/AlgorithShot/issues/new/choose) with the
  bug report or feature request form.
- **A security problem:** do not open an issue; follow [SECURITY.md](SECURITY.md).
- **Contributing:** start with [CONTRIBUTING.md](CONTRIBUTING.md) and the
  [roadmap](ROADMAP.md).
- **Anything else:** email **hello@algorithco.com**.
