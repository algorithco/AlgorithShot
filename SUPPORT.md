# Getting help

- **Using the app:** see the [desktop guide](desktop/README.md). Download the
  newest installer from the
  [latest release](https://github.com/algorithco/algorith-shot/releases/latest).
- **Something doesn't work, or you have an idea:** open an
  [issue](https://github.com/algorithco/algorith-shot/issues/new/choose) with the
  bug report or feature request form.
- **A security problem:** do not open an issue; follow [SECURITY.md](SECURITY.md).
- **Anything else**, including requests for permission to use the code: email
  **hello@algorithco.com**.
