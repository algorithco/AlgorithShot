# AlgorithShot v0.2.2

This release fixes screenshot selection on Linux and macOS and refreshes the
Windows installer.

- Linux capture follows the actual X11 or Wayland session. Wayland uses the
  desktop Screenshot portal, with an image selection window when a system picker
  is unavailable. Cancelled captures can be started again.
- macOS capture uses ScreenCaptureKit on macOS 14 and newer and Core Graphics on
  macOS 12–13. Permission failures show an actionable message.
- Older WebKit versions use a regular canvas when OffscreenCanvas 2D is
  unavailable, keeping image decoding and editing usable.
- The Windows installer has a compact header, readable text, clearer folder and
  progress controls, and consistent welcome, license, maintenance and finish
  pages. Setup and uninstall always use English; there is no language selector.
- Linux packages are built on Ubuntu 22.04 and do not depend on the unused
  PipeWire recording backend.

Install over an existing version to keep screenshots and settings. The update
feed remains in the source repository and uses the existing trusted signing key.

## Downloads and requirements

- **Windows x64:** the `x64-setup.exe` installer.
- **macOS 12 or newer, Intel and Apple Silicon:** the universal `.dmg`.
  Allow Screen Recording access when prompted. The macOS bundle is ad-hoc signed;
  this release does not include Apple Developer ID notarization.
- **Linux x86_64:** `.AppImage`, `.deb` or `.rpm`. WebKitGTK 4.1 is required.
  Wayland needs a working session D-Bus, `xdg-desktop-portal` and a Screenshot
  backend supplied by the desktop environment. Global shortcuts depend on the
  desktop's GlobalShortcuts portal support.

The `.app.tar.gz` archive, five `.sig` files and `latest.json` support in-app
updates. `SHA256SUMS.txt`, build provenance and third-party license texts are
included with the complete release.
