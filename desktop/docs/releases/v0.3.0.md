# AlgorithShot v0.3.0

Open **Record video** on Windows to capture a display or window at 30 or 60 fps.
Press **Ctrl+Shift+F9** to stop and save. The recorder writes silent H.264 MP4
files to the `Recordings` subfolder of your capture folder.

- Timed and repeat screenshots reserve the capture slot until they finish.
- Windows quick cards stay visible above other windows without taking focus.
- The editor saves the selected format and respects the file size limit.
  PNG and WebP at quality 100 preserve the original pixels.
- Privacy checks scan the rendered image and discard results from older edits.
  Solid masks are the default.
- Open **Settings** to find library cleanup. New settings use Ctrl+Shift+A
  for capture and show the quick card for 45 seconds.

## Downloads and requirements

- **Windows x64:** use the `x64-setup.exe` installer. Recording requires Windows
  10 version 2004 or newer, Media Foundation and a compatible GPU encoder.
  Recording currently supports SDR display and window capture without audio.
- **macOS 12 or newer, Intel and Apple Silicon:** use the universal `.dmg`.
  Grant Screen Recording permission for screenshots. The app is ad-hoc signed.
- **Linux x86_64:** use the `.AppImage`, `.deb`, or `.rpm`. WebKitGTK 4.1 is
  required. Wayland capture needs a compatible desktop Screenshot portal.

Install over an existing version to keep screenshots and settings. The update
feed includes signed artifacts for all supported platforms. The release also
includes build provenance, checksums, and dependency licenses.
